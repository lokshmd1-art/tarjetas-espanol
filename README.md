# Tarjetas de Español — Android-приложение

Готовый проект (Capacitor + Android). Дизайн и логика такие же, как в HTML-версии, плюс:
- нужно печатать перевод по-русски (для глаголов — инфинитив, для существительных/прилагательных — мужской род);
- ведётся статистика правильных/неправильных ответов — общая и по темам (кнопка «Статистика по темам» вверху экрана);
- статистика сохраняется на устройстве (localStorage) между запусками.

## Почему нет готового .apk в этой папке

Сборка Android-приложения требует Android SDK и Gradle, которые скачиваются с серверов Google
(`dl.google.com`, `services.gradle.org`). Среда, в которой я работаю, не имеет доступа к этим
серверам — поэтому я не могу физически скомпилировать `.apk` здесь. Зато я подготовил всё, что
нужно, чтобы вы получили готовый файл одним из двух способов ниже — обычно это 5–10 минут.

## Способ 1 (проще всего, ничего не устанавливать) — GitHub Actions

1. Создайте пустой репозиторий на github.com и загрузите туда всё содержимое этой папки
   (например, через github.com → "Add file" → "Upload files", или `git init && git add . && git commit -m "init" && git push`).
2. В репозитории уже лежит файл `.github/workflows/build-apk.yml` — он автоматически соберёт APK
   в облаке при каждом пуше (или запустите вручную во вкладке **Actions → Build Android APK → Run workflow**).
3. Через 3–5 минут откройте последний запуск в **Actions**, внизу будет файл
   **tarjetas-espanol-debug-apk** — скачайте и распакуйте, внутри `app-debug.apk`.
4. Перенесите `app-debug.apk` на телефон и установите (разрешите установку из неизвестных источников).

## Способ 2 — Android Studio на своём компьютере

1. Установите [Android Studio](https://developer.android.com/studio).
2. Откройте папку `android/` как проект ("Open an existing project").
3. Дождитесь синхронизации Gradle (Studio сама скачает нужный SDK).
4. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Если захотите поменять слова или тексты

Все карточки лежат в одном месте: `www/index.html`, в массиве `const items = [...]` — можно
редактировать переводы, примеры, добавлять новые слова. После изменений:
```
npx cap copy android
```
и снова собрать через один из способов выше.
